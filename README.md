# Personal Portfolio Website — Abdelmalek Dev

A modern, fast, and high-performance developer portfolio built to showcase my journey, projects, and technical skills as an Information Systems student and full-stack web developer.

---

## 💡 About The Project

This portfolio is a digital space designed to represent my professional identity and personal philosophy in software development. It delivers an overview of my academic background at USTHB, my core projects, and my approach to problem-solving.

### 🎨 Design Philosophy
The design behind this portfolio balances clean aesthetics with high functional usability. Drawing inspiration from modern UI/UX web trends and crafted with the assistance of **AI tools** for iterative feedback, I customized and refined every layout element to build a distinct, tailored visual identity. Built with a dark-theme aesthetic, custom accent colors, and responsive Bento Grid sections, it reflects my commitment to building ethical, simple, and high-quality digital experiences.

---

## ✨ Key Features

* **⚡ Fast & Lightweight:** Built with Vanilla JavaScript and Tailwind CSS for optimal loading performance without unnecessary dependencies.
* **📱 Fully Responsive Layout:** Designed mobile-first to ensure a seamless experience across mobile, tablet, and desktop screens.
* **🧩 Bento Grid Architecture:** Clean, structured display of personal background, philosophy, and tech interests.
* **✨ Dynamic UI Elements:** Smooth animations, glassmorphism cards, and interactive project showcases.
* **🎯 Clear Contact Section:** Straightforward communication channels for potential clients, collaborators, or employers.

---

## 🛠️ Technologies Used

* **Markup & Structure:** HTML5
* **Styling & Design:** Tailwind CSS (Custom Color Variables, Glassmorphism, Responsive Grid)
* **Interactivity & Logic:** Vanilla JavaScript (ES6+)
* **Icons & Assets:** FontAwesome / Line Icons
* **Hosting & Deployment:** GitHub Pages / Vercel
