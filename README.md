# Personal Portfolio Website — Abdelmalek Dev

A modern, fast, and high-performance developer portfolio built to showcase my journey, projects, and technical skills as an Information Systems student and full-stack web developer.

---

## 💡 About The Project

This portfolio is a digital space designed to represent my professional identity and personal philosophy in software development. It delivers an overview of my academic background at USTHB, my core projects, and my approach to problem-solving.

### 🎨 Design Idea
The design is inspired by modern web trends, refined with AI assistance, and fully customized by me to create a unique, dark-themed visual identity that focuses on simplicity and clarity.

---

## ✨ Key Features

* **⚡ Fast & Lightweight:** Built with Vanilla JavaScript and Tailwind CSS for optimal loading performance.
* **📱 Fully Responsive Layout:** Designed mobile-first to ensure a seamless experience across mobile, tablet, and desktop screens.
* **🧩 Bento Grid Style:** Clean, structured display of personal background, philosophy, and tech interests.
* **✨ Dynamic UI Elements:** Smooth animations, glassmorphism cards, and interactive project showcases.
* **🎯 Clear Contact Section:** Straightforward communication channels for potential clients, collaborators, or employers.

---

## 🛠️ Used Technologies

* **Markup & Structure:** HTML5
* **Styling & Design:** Tailwind CSS (Custom Color and Fonts Variables, Glassmorphism, Responsive Grid)
* **Interactivity & Logic:** Vanilla JavaScript (ES6+)
* **Icons:** FontAwesome
* **Animations:** Animate On Scroll Library (AOS)
* **Hosting & Deployment:** GitHub Pages
